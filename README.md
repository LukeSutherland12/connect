# New Company

They build the home. We handle the site.

A working test build of the Builder Services App mockups: sign up, set the site, book transport, crane, consent and other site services, track them live, upload plans and order materials by stage.

Live: https://lukesutherland12.github.io/new-company/

## Accounts

- **Test mode (default):** with `config.js` blank, accounts and bookings are saved in each person's own browser.
- **Shared accounts:** create a free Supabase project, run `supabase-setup.sql` in its SQL Editor, then paste the project URL and anon key into `config.js`. For quick testing, turn off "Confirm email" under Authentication → Providers → Email.

Prices, company names and turnaround times are placeholders in [BRACKETS] until they're set.
